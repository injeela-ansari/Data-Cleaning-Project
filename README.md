# 🚀 Data Science Internship - Month 1 Practical Tasks

Welcome to my repository for the **Data Science Internship at Nascent IT Ventures**. This project contains a series of execution-focused tasks completed during the first month, covering Python basics, Data Manipulation, Cleaning, and Exploratory Data Analysis (EDA).

---

## 📌 Project Overview
The goal of these tasks was to learn by doing—moving from manual Python calculations to building an end-to-end data analysis pipeline.

## 📂 Repository Structure

| Task | File Name | Description |
| :--- | :--- | :--- |
| **Task 1** | `task1_analysis.ipynb` | Python basics: Manual statistics, Dictionary operations, and File I/O. |
| **Task 2** | `task2_analysis.ipynb` | Pandas & NumPy: Data loading, filtering, and grouping on 500+ rows. |
| **Task 3** | `task3_analysis.ipynb` | Data Cleaning: Handling missing values, duplicates, and type conversion. |

## 🛠️ Key Highlights

### 1. Python Foundations (Task 1)
* Calculated Mean, Median, Min, and Max **manually** without using external libraries.
* Implemented student record management using Python Dictionaries.

### 2. Data Manipulation & Cleaning (Task 2 & 3)
* Worked with `sales_data.csv` and `cleaned_employee_data.csv`.
* Handled missing values using **Mean/Median/Mode imputation**.
* Performed advanced grouping and filtering to extract specific data segments.

### 3. Exploratory Data Analysis (Task 4)
* Generated 5+ professional plots including Distribution plots, Heatmaps, and Bar charts.
* **Key Insight:** Correlation analysis showed that Unit Price is the primary driver of revenue in the e-commerce dataset.

### 4. Mini Project: Telecom Churn Analysis (Task 5)
* **Objective:** Identify key drivers of customer attrition.
* **Key Findings:** * **Month-to-month** contract holders have the highest churn rate.
    * Higher **monthly charges** are directly correlated with customer attrition.
    * Newer customers (**0-6 months tenure**) are the most vulnerable group.
